# Licensing

PCAM v3 uses a path-based licensing model:

- specification and documentation: CC BY 4.0
- reference and independent implementation code: MIT
- schemas, build metadata, and tooling: MIT
- conformance vectors and external test data under `tests/`: CC0 1.0

The [repository licensing map](https://github.com/GreyforgeLabs/pcam/blob/main/LICENSES/README.md) controls exact paths. The project also publishes separate [trademark](https://github.com/GreyforgeLabs/pcam/blob/main/TRADEMARKS.md) and [patent](https://github.com/GreyforgeLabs/pcam/blob/main/PATENTS.md) statements.
