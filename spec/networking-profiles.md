# PCAM v3 Networking Profiles

Status: Normative Candidate companion

Owner: PCAM specification

The master authority is `PCAM-v3.md` §29.

PCAM Core does not prescribe transport or topology. Local deterministic, lockstep, rollback, and server-authoritative prediction profiles each require complete authoritative state and a declared deterministic host contract. Phase-only correction is not rollback.

This companion is an index, not a second normative definition.
