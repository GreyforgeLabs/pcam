# PCAM v3 Interaction Model

Status: Normative Candidate companion

Owner: PCAM specification

The master authority is `PCAM-v3.md`, especially §19-23 and §24 stages 7-10.

Interactions are directed candidates evaluated from one frozen semantic snapshot. Typed rules run through admission, routing, modification, materialization, and reaction. Authoritative ledgers control repeated contact. Effects reduce and commit only after candidate resolution.

This companion is an index, not a second normative definition.
