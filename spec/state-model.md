# PCAM v3 State Model

Status: Normative Candidate companion

Owner: PCAM specification

The master authority is `PCAM-v3.md`, especially §3, §6-7, §18, §22, §25-28, and §30-31.

The complete serialized action-machine state is authoritative. Phase, node, animation frame, and presentation time are insufficient unless they encode every future-influencing value. State includes monotonic logical tick, entity and action records, resource and slot ownership, buffers, events, freeze tokens, ledgers, RNG streams, identifier generators, host authority, extension state, and deterministic fault state.

This companion is an index, not a second normative definition.
